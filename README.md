# Solución al Desafío de Frontend Mentor: Componente de Almacenamiento de Datos con Tooltip y Barra de Progreso

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Fylo Data Storage Component** de Frontend Mentor. El objetivo era crear una página estática con un diseño responsivo que incluye un **tooltip** y una **barra de progreso** para mostrar el uso de almacenamiento de datos.

**Desafío de Frontend Mentor:** [Fylo Data Storage Component](https://www.frontendmentor.io/challenges/fylo-data-storage-component-1dZPRbV5n)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/fylo-data-storage-component-master-github-io/)

## Descripción del Proyecto

Este proyecto es una página estática que presenta un componente de almacenamiento de datos con las siguientes características:

- Un **tooltip** que muestra cuánto espacio de almacenamiento queda disponible.
- Una **barra de progreso** que indica cuánto espacio se ha utilizado.
- Un diseño responsivo que se adapta a diferentes tamaños de pantalla, desde dispositivos móviles hasta desktop.

El diseño es completamente responsivo, utilizando **CSS Flexbox** y **CSS Grid** para organizar los elementos de manera eficiente y visualmente atractiva.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.
- **Interactividad**: Tooltip y barra de progreso implementados con JavaScript y CSS.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
